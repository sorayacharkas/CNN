# CNNs from the ground up

A guided project on convolutional networks: writing a 2D convolution by hand, output sizes, padding and edge detection (on the Chicago skyline), then building and training CNNs in PyTorch.

- `cnn_from_scratch.ipynb`: code + written answers

Python, NumPy, SciPy, PyTorch. Artificial Neural Networks course, Sharif University of Technology (2023).
